Kalkulator 

Apk Kalkulator berbasis web ini saya buat untuk salah satu project praktek mandiri saya setelah mengikuti kursus 
pengembangan web,aplikasi ini bertujuan untuk membantu kita menghitung angka lebih mudah dan cepat ,sehingga tidak harus menghitung secara manual.

FITUR
-Tombol Button Angka(0-9) 
-Operasi Aritmetika
-Menampilkan hasil perhitungan
-Tombol clear untuk menghapus input

TEKNOLOGI
-HTML
-CSS
-JavaScript 
-DOM Manipulation
